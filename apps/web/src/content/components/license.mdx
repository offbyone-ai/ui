```sh

```

This also installs `button`, `drawer`, and `input` from shadcn if not already present.

## Usage

Wrap your app with `LicenseProvider`, passing your payment configuration:

```tsx
import { LicenseProvider } from "@/lib/license"

export default function App({ children }) {
  return (
    <LicenseProvider
      appName={config.name}
      appId={config.pay.appId}
      priceId={config.pay.priceId}
      price={config.pay.price}
      payUrl={config.pay.url}
      appDescription="Buy once, use forever."
      supportUrl={config.links.text()}
    >
      {children}
    </LicenseProvider>
  )
}
```

Gate content with the `useLicense` hook:

```tsx
import { useLicense } from "@/lib/license"

export function PremiumFeature() {
  const { licensed, openPaywall } = useLicense()

  if (!licensed) {
    return (
      <button onClick={() => openPaywall("Unlock this feature.")}>
        Upgrade to access
      </button>
    )
  }

  return <div>Premium content</div>
}
```

### Server-verified license check with `requireLicense`

The `licensed` boolean is derived from `localStorage` on mount — it's fast but trusts whatever was saved locally. `requireLicense()` goes further: it reads the stored identity and makes a live call to your payment backend to confirm the license is still valid. This catches edge cases like refunds or revoked licenses.

Use it to gate actions that matter (downloads, exports, generation) rather than rendering:

```tsx
import { useLicense } from "@/lib/license"

export function DownloadButton() {
  const { requireLicense, openPaywall } = useLicense()

  async function handleDownload() {
    try {
      if (!(await requireLicense())) {
        openPaywall("Download requires a license.")
        return
      }
    } catch {
      toast.error("Unable to verify license — check your connection and try again.")
      return
    }

    // proceed with download
  }

  return <button onClick={handleDownload}>Download</button>
}
```

`requireLicense` returns `false` (and clears local state) if there's no stored identity or if the server says the license is invalid. It throws on network failure, so wrap it in a try/catch to handle connectivity issues gracefully.

## API Reference

### LicenseProvider Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `appName` | `string` | ✓ | Displayed in the paywall title and description |
| `appId` | `string` | ✓ | Unique app identifier sent to the payment API |
| `priceId` | `string` | ✓ | Price ID passed to the checkout endpoint |
| `price` | `number` | ✓ | Display price in USD (e.g. `29` → "$29.00 one time") |
| `payUrl` | `string` | ✓ | Base URL of your payment server |
| `appDescription` | `string` | — | Subtitle shown in the paywall when no reason is provided |
| `supportUrl` | `string` | — | Link shown in the "Need help?" button; omitted if not set |

### useLicense Hook

```tsx
const {
  licensed,         // boolean — whether the user has a valid license
  paywallOpen,      // boolean — whether the paywall drawer is open
  openPaywall,      // (reason?: string) => void
  closePaywall,     // () => void
  startCheckout,    // () => Promise<void> — redirects to Stripe checkout
  restoreByEmail,   // (email: string) => Promise<boolean>
  requireLicense,   // () => Promise<boolean> — re-validates with server
  revoke,           // () => void — clears stored license
  onBeforeCheckout, // (fn: () => void | Promise<void>) => void
  onPaymentSuccess, // (fn: () => void | Promise<void>) => void
} = useLicense()
```

### Standalone API Functions

You can call these directly without `LicenseProvider`:

```tsx
import { createCheckout, verifySession, restoreByEmail } from "@/lib/license"

const url = await createCheckout({ payUrl, appId, priceId })
const paid = await verifySession({ payUrl, appId }, sessionId)
const found = await restoreByEmail({ payUrl, appId }, email)
```
